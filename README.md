# meus-projetos

## Projetos

### [busca-vagas-br](busca-vagas-br/)

Fluxo de candidatura a vagas assistido por IA, rodando localmente com o Claude
Code: avalia anúncios contra o seu perfil, gera currículo e carta de
apresentação direcionados por vaga, e prepara a entrevista.

Adaptação para o mercado brasileiro do
[ai-job-search](https://github.com/MadsLorentzen/ai-job-search) (MIT).

Abra o Claude Code **dentro de `busca-vagas-br/`** — é lá que ficam o `.claude/`
e o `CLAUDE.md` que definem os comandos.
